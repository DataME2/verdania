# Verdania

*Can an economy serve humanity?*

A project of **Let's the Data Talk**. Try it at [verdania.datamanagementengineer.com](https://verdania.datamanagementengineer.com).

## What is Verdania?

Verdania is much more than an educational website: it presents an interactive economic laboratory where people can experiment with economic models, public policies and virtual investment, and observe their consequences on prosperity, inequality and the environment.

Verdania is an imaginary country of 2,000,000 people whose economy is built on farming. Its people are not real: they are generated by computer, so their lives can be studied without touching anyone's privacy. The name comes from the Latin *viridis* (green), for farming, growth and prosperity.

## The starting hypothesis

The platform's initial hypothesis is that markets and private ownership, without sufficient social protections and public-interest safeguards, can produce outcomes that undermine social justice.

Verdania lets you test this hypothesis through transparent simulations. A hypothesis is a starting point, not a verdict: the simulation doesn't assume the answer, so your experiments may support it, add nuance to it or contradict it.

Behind it sits a bigger question: can an economy keep the benefits of markets and private investment while making prosperity serve everyone?

## What you can do

- **Run experiments.** Change taxes, wages, public services and who owns businesses. See what happens to growth, incomes, poverty, inequality and public debt, how certain each result is, and why it changed.
- **Compare economic systems.** Start from one of four models, from market-led capitalism to collective ownership, and adjust any of their rules. A system's name never changes the result; only its policies do.
- **Invest virtual money.** With an account you receive 100,000 virtual units to put into Verdania's projects: farming, clean energy, housing, healthcare, education and more. Each project shows what it pays investors separately from what it does for people and the environment.
- **Save and share.** Save an experiment, publish it for others, and let anyone re-run it to check that it gives exactly the same results.

You can explore everything without an account. You only need to sign in (with Google) to save experiments and invest virtual money.

## Ground rules

- **No real people.** Everyone in Verdania is synthetic.
- **No real money.** Virtual units can't be bought, sold, transferred or cashed out. Nothing here is investment advice.
- **No forecasts.** Results show what a simplified model calculates for an imaginary country. They don't predict what will happen anywhere real.
- **Nothing hidden.** Every assumption is visible, and the full model is published in [`docs/economic-model.md`](docs/economic-model.md).

Today, environmental effects come from each investment project's own notes; a later version of the simulation will calculate them.

| [`sim/`](sim/) | `verdania-sim`: Python engine + FastAPI service |
| [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | All of the checks below, on every pull request |
| [`supabase/`](supabase/) | Migrations (schema + engine-generated reference data), RLS / ledger checks. Migrations deploy to production on merge to `main`. |

```bash
# engine: accounting identities, calibration, determinism, API (Python 3.11+, uv)
cd sim && uv run pytest

# database: all migrations (schema + reference data) + RLS + virtual ledger, on in-memory Postgres (no Docker)
npm i -D @electric-sql/pglite && node supabase/checks/run.mjs

# website: lint, unit tests, production build, then end-to-end + accessibility + mobile (site and engine running)
cd web && npm run lint && npm test && npm run build && npm run e2e

# regenerate the reference-data migration from the engine (only before it is deployed;
# a new model version gets a new migration)
cd sim && uv run python -m verdania_sim.seed
```

Run the engine locally: `cd sim && SIM_DEV=1 uv run uvicorn verdania_sim.api:app --reload`. In any shared environment, set `SIM_API_KEY` instead.
